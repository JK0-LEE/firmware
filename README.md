# Seeed Studio XIAO ESP32-C5 / PlatformIO

在 VS Code 中使用「檔案 → 開啟資料夾」開啟本資料夾。PlatformIO IDE 會讀取 `platformio.ini`，目標板為 `seeed-xiao-esp32-c5`，框架為 Arduino。

`src/main.cpp` 是內建 LED 每秒切換一次的起始範例，序列埠速率為 115200。

板子設定依照 [Seeed Studio 的 PlatformIO 指南](https://wiki.seeedstudio.com/xiao_esp32c5_with_platformio/)。首次使用時，PlatformIO 可能需要下載 Seeed 平台及相關套件。
